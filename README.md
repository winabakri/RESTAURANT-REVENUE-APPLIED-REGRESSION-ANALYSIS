# Restaurant Revenue Applied Regression Analysis | Multiple Linear Regression

## Project Overview
A statistical analysis project investigating factors associated with restaurant revenue using SAS OnDemand. Multiple Linear Regression was applied to examine the relationships between revenue and key business variables, including number of customers, menu prices, and average customer spending.

## Objectives
- Identify key factors associated with restaurant revenue.
- Examine relationships between customer volume, menu pricing, average spending, and revenue.
- Apply statistical modelling to support data-driven business decisions.
- Interpret model results to derive actionable business insights.

## Tools & Technologies
- SAS OnDemand
- Multiple Linear Regression
- Statistical Analysis
- Exploratory Data Analysis (EDA)
- Regression Model Interpretation
- Business Performance Analysis

## Methodology
1. Prepared and explored the restaurant dataset.
2. Developed a Multiple Linear Regression model using SAS OnDemand.
3. Evaluated the relationships between potential revenue drivers and restaurant revenue.
4. Interpreted the model results to identify statistically significant factors, where supported by the analysis.

## Key Business Value
Demonstrates the application of statistical modelling to understand revenue drivers, assess business performance, and support evidence-based decision-making.

## Project Deliverables
- SAS analysis and regression model output, where available.
- Statistical findings and interpretation.
- Summary of key revenue drivers identified through the analysis.
